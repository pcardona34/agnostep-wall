# agnostep-wall
Setting your wallpaper on every AGNoStep flavour. This is a module of [AGNoStep](../../../agnostep) project.

With different ways to show or hide the background, depending on the Window Manager and the Workspace Manager, it could be hard to set the wallpaper or the colour background in each case.

So We try to provide a way to manage every case.

This is a work in progress, tied to the 3rd release of AGNoStep. Coming soon.
